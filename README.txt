README – UUI projekt

Naziv projekta:
Usporedba CNN arhitektura za klasifikaciju slika

Opis:
Projekt je izrađen u sklopu kolegija Uvod u umjetnu inteligenciju (UUI).
Cilj projekta je ispitati utjecaj različitih arhitektura konvolucijskih
neuronskih mreža (CNN) na kvalitetu klasifikacije slikovnih podataka.
U projektu se uspoređuju tri CNN modela trenirana nad skupom podataka
Fashion-MNIST.

Korištene tehnologije:
- Python
- Google Colaboratory / Jupyter Notebook
- TensorFlow, Keras
- Fashion-MNIST skup podataka

Datoteke:
- usporedba_CNN_arhitektura.ipynb – implementacija i evaluacija modela
- README.txt – opis projekta i upute

Upute za pokretanje:
1. Otvoriti Google Colaboratory
2. Učitati datoteku usporedba_CNN_arhitektura.ipynb
3. Pokrenuti sve ćelije redom (Run all)
